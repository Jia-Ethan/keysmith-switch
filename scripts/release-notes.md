# Keysmith Switch v0.2.4

修复确认部署被拒绝的问题，并带来全新的界面：左侧 Agent 栏、更好懂的部署确认、⌘K 命令面板，以及可以编辑机器上正在用的提示词。

## 这一版有什么

**修复**

- 修复应用要求的适配器版本落后于随包适配器（Claude Code 7.2、Codex 0.6.0、Grok 0.6.1、ZCode 0.3.2），导致确认部署时被判定为“版本不匹配”而拒绝的问题。
- 修复 Claude Code 刚部署完提示词，状态却显示“未部署”的问题：读取状态时不再要求终端包装脚本。
- 从提示词库删除的提示词，不再被当作“正在使用的库提示词”显示。

**新的界面**

- 顶部导航换成左侧竖向的 Agent 栏，选中的 Agent 有一圈跟随主题色的光晕，去掉了原来的下划线。
- 首页顶部大字显示“正在使用”的提示词；“移除当前部署”改称“停用”。
- 部署确认改成一句话加“现在 → 部署后”的图示，说明会替换什么、原来的内容会先自动备份；文件、备份、指纹等细节收进“详细信息”，默认折叠，出问题时用文字说明。
- 新增 ⌘K（Windows 为 Ctrl+K）命令面板：切换 Agent、新建并部署、直接部署库里的提示词。按钮、卡片和首页顶部也有了更明显的交互反馈；系统开启“减少动态效果”时会自动关闭这些动画。

**编辑机器上正在用的提示词**

- 首页和“现在正在用的提示词”卡片上新增“编辑”和“收入库并编辑”。会把机器上的提示词读回提示词库再打开编辑器，读不出来时改为打开粘贴框。
- 只有读到的内容与适配器报告的指纹一致才会收入库，不会猜；Codex 因为适配器不提供指纹，读取它配置里指向的提示词文件，且该文件必须在 Codex 目录内。
- 保存编辑不会改动机器上的内容，需要重新部署才会生效，保存时会有提示。

**命名**

- 界面文案和文档统一称 “Claude Code”，指开源的 Claude Code 命令行工具，不是 Claude 桌面版的聊天。

## 安装

- 已安装的版本可以在应用内点「检查更新」升级到 `v0.2.4`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.2.4_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.4_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
