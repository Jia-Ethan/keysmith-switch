# Keysmith Switch v0.2.8

修复点击部署按钮时卡片闪烁的问题，并新增“清理”和“回滚”。

## 这一版有什么

- **卡片不再闪烁**：之前把指针停在卡片的“部署”按钮上时，卡片会来回抖动。现在按钮和卡片的悬停效果已经分开，点击确认部署的过程中也保持稳定。
- **清理**：每个 Agent 页面新增“清理”按钮。它会停用正在部署的提示词；Claude Code 还会清空 `~/.claude/CLAUDE.md`，包括你自己写在里面的内容（需要先勾选确认）。只清理 Keysmith 部署的内容和这个记忆文件，不会动你的项目文件。
- **清理前先存一个版本**：清理前会把当时部署的提示词和 `CLAUDE.md` 的原样内容保存起来，放在 `~/.keysmith-switch/snapshots/`。
- **回滚**：设置里新增“版本”页，列出保存的版本，可以回滚或删除。回滚会重新部署当时的提示词并把 `CLAUDE.md` 恢复原样；如果会覆盖现在的内容，会先把现在的状态另存一个版本，所以回滚本身也能撤销。
- **都是先预览再确认**：清理和回滚都和部署一样，先给你看会发生什么，确认后才执行。
- **目前的范围**：只有 Claude Code 有已知的记忆文件；Codex、Grok Build、ZCode 的清理只会停用部署。保存的版本不在导出的备份里，“清除全部数据”也不会删除它们，需要在“版本”页单独删除。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.2.8`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.2.8_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.8_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
