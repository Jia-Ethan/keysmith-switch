# Keysmith Switch v0.6.2

提示词卡片支持右键菜单：删除、复制、复制到其他工具，以及打开、编辑和部署，在列表里就能完成。

## 这一版有什么

- **右键提示词卡片会弹出操作菜单。**
  - 普通卡片：打开、编辑、部署、复制、复制到其他工具（另外三个 Agent）、删除。删除前仍会弹出确认框。
  - 正在生效的卡片：「部署」换成「停用」。「删除」暂时不可用，并提示先停用。删掉正在运行的提示词，列表会把它显示成「还没放进提示词库」。
  - 拓展包里的提示词：只能部署和删除。它们的内容不公开，所以不提供打开、编辑和复制。
  - 有部署计划在准备或确认时，会改动内容的操作暂时不可用。
- **提示词详情页的「⋯」菜单使用同样的规则：** 正在生效的提示词不能直接删除，需要先停用。
- **右键不再弹出系统菜单。** 以前在页面任意位置右键，都会出现「重新载入」等系统菜单项，误点会丢掉快速部署里的草稿和没保存的编辑。现在只有在输入框里和选中的文字上，右键才会出现系统菜单（剪切、复制、粘贴等）。
- 菜单可以用方向键选择，按 Esc、点空白处、滚动页面或切换窗口都会关闭。

## 安装

- 已安装 `v0.1.3` 及以上的版本，可以在应用内点「检查更新」升级到 `v0.6.2`，安装仍需你确认。
- macOS Apple Silicon：`Keysmith.Switch_0.6.2_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.6.2_x64-setup.exe`

安装包没有使用 Apple Developer ID、公证或 Windows Authenticode。更新包用独立的生产 minisign 密钥签名，这不是平台代码签名。
