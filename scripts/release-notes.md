# Keysmith Switch v0.2.6

新增“拓展包”：官方发布的提示词包，可以单独更新，不用更新 App。

## 这一版有什么

- **拓展包页面**：左侧栏新增“拓展”按钮。页面里列出官方拓展包，可以安装、更新和卸载，官方发布的包带“官方”标记。
- **默认关闭，打开才联网**：在“拓展”页点“打开拓展包”之前，App 不会读取网络。打开后只读取官方拓展源的清单和你选择安装的包，不会上传你的任何内容。
- **只进提示词库，不自动部署**：安装只会把提示词放进提示词库，部署到 Agent 仍然要你在确认单里点确认。
- **不会覆盖你的修改**：更新时，你没改过的提示词会直接更新（保留历史版本）；你改过的保持原样，新的内容另存一份；你删掉的不会回来。卸载只会移除你没改过、也没在使用的提示词。
- **有更新会提醒**：拓展包有新版本时，“拓展”按钮上会出现红点。打开拓展包后，App 会每 6 小时在后台看一次，窗口回到前台超过 1 小时也会看。
- **检查规则**：拓展包只含数据，没有可执行代码。每个包下载后，App 会核对清单里的大小和哈希，并逐项检查内容；下载地址必须在官方仓库之下。拓展源目前没有签名，这一点写在 README 里。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.2.6`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.2.6_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.6_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
