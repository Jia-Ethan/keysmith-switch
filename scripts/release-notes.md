# Keysmith Switch v0.2.0

界面整体重做：每个 Agent 有自己的工作区，首页就是提示词库，快速部署变成一个随时呼出的编辑面板。部署前仍然先审阅计划再确认，写入仍由现有 adapter 完成。

## 这一版有什么

- 首页即工作区。顶部横幅显示当前 Agent 是否已部署、部署在哪个范围、部署的是哪条提示词，移除与刷新也在这里。下方是提示词库：当前部署的条目置顶，其余卡片可一键部署，同样先生成部署计划、确认后才写入。
- 快速部署改为弹出面板（⌘N / Ctrl+N）。粘贴自己的提示词和标题，或导入、直接拖入 `.md` 文件；实时显示字数和行数；可以只保存到提示词库，或按 ⌘↵ / Ctrl+↵ 生成部署预览。关闭面板草稿仍在。
- 快速部署不再绑定四套 Keysmith 官方提示词正文，默认离线工作，不从兄弟仓库的远程分支抓取内容。同一 Agent 下相同正文复用既有条目，不会悄悄改写其标题或标签。交给 adapter 的临时输入只包含提示词正文，确认时重新校验内容哈希、版本和 adapter 状态。
- 每个 Agent 有自己的主题色：Claude 橙、Codex 墨绿、Grok 银灰、ZCode 紫。切换时颜色平滑过渡。
- 部署预览重新排版：文件改动带动作标签，备份单独列出，内容指纹显示「当前 → 目标」，警告与重载提示分开呈现。检测到漂移时可在预览里直接从备份恢复。
- 部署成功后有一个短暂的确认动效；开启「减少动态效果」时改为静态提示。
- 快捷键：⌘1–4 / Ctrl+1–4 切换 Agent，⌘, / Ctrl+, 打开设置，/ 或 ⌘F / Ctrl+F 搜索，⌘R / Ctrl+R 刷新状态。完整列表在「设置 › 通用」。
- macOS 隐藏原生标题栏，红绿灯并入应用顶栏，拖动顶栏即可移动窗口。Windows 保留原生标题栏。
- 修复深色模式下编辑器行号栏与当前行仍为浅色的问题。
- 保留每次运行只读一次本机状态、显式刷新、关闭窗口即退出的行为。四个 Agent 继续使用随包提供的 legacy adapter。

## 安装

- 已安装 `v0.1.3` 及以上：可以在应用内检查更新到 `v0.2.0`；安装仍需用户确认。
- 仍在 `v0.1.1`：内置的是测试 updater 公钥，必须手动安装本版本。
- macOS Apple Silicon：`Keysmith.Switch_0.2.0_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.0_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
