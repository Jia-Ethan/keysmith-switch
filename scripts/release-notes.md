# Keysmith Switch v0.3.3

修复 Codex 清理后无法再部署的问题，并让扩展包里的提示词不再公开明文。

## 这一版有什么

- **Codex 清理后可以重新部署了**：之前清理会把 `~/.codex/config.toml` 搬走，而 Codex 的部署需要这个文件，之后每次部署都失败，界面上只显示 `ok=false`、`exit 1`。现在缺少这个文件时部署会自动补一个，失败时也会显示真正的原因。
- **清理不再带走 Codex 的 `config.toml`**：这个文件里有你的模型、服务商、插件和已信任的项目，之前清理一次就全丢了。现在清理会保留它；登录信息仍然会被清掉。
- **“当前未部署”与“部署中”不再互相矛盾**：Codex 的提示词文件被手动改过后，页面顶部会正常显示正在使用的提示词，并提示配置被手动改过，可以重新部署，或用“清理”从头开始。
- **扩展包里的提示词不公开明文**：从扩展包装进来的提示词，列表里只显示标题和标签，卡片点不开，也不能编辑、复制或对比版本，部署照常使用。你自己导入、自己写的提示词不受影响，可以照常查看和编辑。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.3.3`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.3.3_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.3.3_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
