# Keysmith Switch v0.1.8

本机部署状态在一次运行里只读一次。关闭窗口就是退出。界面语言改成页内下拉。顶栏、首屏和设置换成同一套界面。

## 这一版有什么

- 四个工具各自记住已部署或未部署。切回来不再显示「正在读取本机状态」。同一次读取不会重复发起。部署成功或卸载成功直接改掉记住的状态，不用刷新。卡片上的刷新是唯一会重新读取本机的入口。重新打开应用会再读一次。读取失败停在原来那颗按钮旁边，不会反复重读。
- 读取进行时，按钮位置是一枚不确定进度环。开启「减少动态效果」后旋转停止，圆环仍在，能看出正在读取。
- 关闭窗口即退出。没有托盘图标，没有后台进程，没有开机启动，也没有静默启动。只有未保存草稿、并且选择不放弃时，窗口才留下。
- 界面语言是页内下拉：简体中文、繁體中文、English。不再使用会盖住主题选项的系统浮层。
- 顶栏、首屏卡片、设置的通用 / 工具 / 关于共用同一套界面：暖色底、单一铜色强调、一个圆角台阶。

## 安装

- 已安装 `v0.1.3` 及以上：可以在应用内更新到 `v0.1.8`。
- 仍在 `v0.1.1`：内置的是测试 updater 公钥，必须手动安装本版本。
- macOS Apple Silicon：`Keysmith.Switch_0.1.8_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.1.8_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名。
