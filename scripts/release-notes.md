# Keysmith Switch v0.2.5

有新版本时，应用会主动提醒你；检查更新的过程更顺滑；左上角换了更精致的图标。

## 这一版有什么

- **新版本提醒**：有新版本发布时，左侧栏的设置图标和“关于”标签页上会出现红点。检查过程中红点不会闪灭。
- **自动发现新版本**：应用开着不关也能发现新版本。之前只在启动时检查一次；现在每 6 小时在后台再查一次，窗口重新回到前台且距上次检查超过 1 小时也会查。后台检查不会打扰你：不显示“正在检查”，失败也不报错。在设置里关闭“自动检查更新”后，这些都不会发生。
- **检查更新更流畅**：“关于”页的更新区域重新设计。一个图标随状态变化（检查时光环旋转、已是最新时对勾一笔画出、有新版本时光晕外扩），文字平滑出现，需要操作的按钮和说明是展开出来的。整块卡片不再上下跳动，新一轮检查期间会保留上一次的结果，不会先消失再出现。系统开启“减少动态效果”时会自动简化动画。
- **左上角图标**：直接使用应用本身的高清图标，去掉了外面多余的一层方框，移上去会轻轻抬起并倾斜；点击它会打开“关于”页。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.2.5`；安装仍需用户确认。
- 红点提醒从这一版开始才有：从 `v0.2.4` 及更早版本升级后，之后的新版本才会自动提醒你。
- macOS Apple Silicon：`Keysmith.Switch_0.2.5_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.5_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
