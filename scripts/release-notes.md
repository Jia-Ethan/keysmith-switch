# Keysmith Switch v0.3.7

修复 Windows 上反复弹出命令行窗口，以及使用系统代理时无法检查更新的问题。

## 这一版有什么

- **Windows 上不再弹出命令行窗口**：之前只有读取状态时做了处理，检查更新、检测和安装官方 CLI、取消任务、清理前的进程检查、反馈入口都会弹黑窗。现在这些都不再弹窗。
- **使用系统代理时可以检查更新**：之前检查更新强制不走任何代理，Windows 上用 Clash、v2rayN 等设置系统代理的用户，会看到「offline: curl: (28) Operation timed out」。现在会读取 Windows 系统代理；设置了 `https_proxy` 或 `all_proxy` 环境变量时优先使用环境变量。本机地址始终不走代理。
- **检查更新的等待时间从 20 秒延长到 30 秒**：网络较慢时不容易误报超时。

## 已知情况

- 这一版的 Windows 修复没有在真实 Windows 机器上完整验证过。如果仍然遇到弹窗或更新失败，请通过应用内的反馈入口告诉我们。
- 应用内下载安装更新这一步由 Tauri 更新插件完成，这一版没有改动它。如果下载阶段仍然失败，请从发布页手动下载安装包。
- 不使用代理也无法直接访问 GitHub 的网络环境，这一版仍然无法在应用内更新，请从发布页手动下载。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.3.7`；安装仍需用户确认。**如果你正受上面的更新超时影响，应用内更新可能无法成功，请直接从发布页下载安装包安装一次，之后的更新就会正常。**
- macOS Apple Silicon：`Keysmith.Switch_0.3.7_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.3.7_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
