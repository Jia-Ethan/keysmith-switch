# Keysmith Switch v0.2.9

修复“检查更新”时界面闪烁、像卡住的问题，并让 Codex 的“清理”能清空 `AGENTS.md` 和记忆文件夹。

## 这一版有什么

- **检查更新不再闪烁**：之前点一次“检查更新”，图标会换成转圈再换回来，文字也会淡出淡入两次，转圈每转一圈还会停顿一下。现在图标保持不变，只在外面转一圈匀速的光环，结果没变时文字原地更新。
- **Codex 也能清理 `AGENTS.md`**：之前 Codex 的“清理”只会停用 Keysmith 部署的内容，`AGENTS.md` 不会动，Codex 没部署时连“清理”按钮都看不到。现在 Codex 页面始终有“清理”，会清空 `~/.codex/AGENTS.md`（包括你自己写的内容），和 Claude Code 的 `CLAUDE.md` 一样先要求勾选确认。
- **记忆文件夹可以选择清理**：弹窗里有单独的勾选框，**默认不勾选**；勾选后会把整个 `~/.codex/memories` 文件夹移进保存的版本里，不复制也不删除，并留下一个空文件夹。Codex 正在运行时不能清理，需要先退出。
- **回滚**：“设置 → 版本”里的回滚现在也会恢复 `AGENTS.md` 和记忆文件夹；现有的内容会先另存为一个新版本，保存的版本本身保持完整，可以再次回滚。
- **不会动的东西**：Codex 的数据库、会话等其他文件，项目目录里的文件，以及你的提示词库。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.2.9`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.2.9_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.9_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
