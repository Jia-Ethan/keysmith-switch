# Keysmith Switch v0.2.7

修复 ZCode 无法部署和 Grok 配置被改动后无法部署的问题，部署失败时会说清真正的原因。

## 这一版有什么

- **ZCode 现在可以部署了**：之前在 macOS 上，ZCode 安装时会读取自己的脚本文件，而打包进 App 的程序里没有这个文件，安装会直接失败。现在已经一起打包，构建时也会检查，缺了就不通过。
- **Grok 配置被改动后可以修复**：如果 Grok 配置文件里 Keysmith 管理的几行被挪动或改写过，部署会被拒绝。现在部署对话框会用中文说明原因，并提供“整理配置”：先预览，你确认后会先备份配置文件，再把这几行放回原位，你自己的设置原样保留。整理完成后会自动重新生成刚才被拦下的部署。
- **部署失败时说清原因**：一份部署计划只能确认一次。之前失败后还能再点一次，然后出现“没有确认过的计划”这种看不懂的提示，把真正的原因盖住了。现在失败后会显示真实原因（技术输出折叠在“详细信息”里），原来的确认按钮置灰，改为“重新生成计划”。
- 部署被拦下时，不再列出 `ok=false`、`exit 1` 这类没有意义的原因，重复的警告也合并了。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.2.7`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.2.7_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.2.7_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
