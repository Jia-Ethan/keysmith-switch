# Keysmith Switch v0.3.4

拓展包有更新时更容易发现，也更容易一次装好。

## 这一版有什么

- **侧栏显示可更新的数量**：之前拓展包有更新时，左侧栏的拓展按钮只有一个小红点，看不出有几个包要更新。现在会显示数字（超过 9 个显示 9+），全部是最新时不显示。公告按钮的未读提示也改成了数字。
- **一键全部更新**：有两个及以上的包可更新时，拓展包页面顶部会出现「全部更新」，逐个装好后汇总结果；中途有包失败，会告诉你已经更新了几个、失败的原因是什么。
- **更新前后的版本一目了然**：可更新的包会显示 `v旧版本 → v新版本`，并排在列表最前面。
- **手动检查有结果提示**：点「检查更新」后，会提示「全部已是最新」或「发现 N 个可更新」。上次检查的时间改成「刚刚」「3 分钟前」这样的说法，鼠标停在上面可以看到具体时间。
- **「停用拓展包」前先确认**：之前页面顶部的「关闭」看起来像关闭页面，点了却会直接关掉拓展包功能。现在改名为「停用拓展包」，点了会先说明已装入的提示词会保留，再让你确认。

## 安装

- 已安装 `v0.1.3` 及以上的版本可以在应用内点「检查更新」升级到 `v0.3.4`；安装仍需用户确认。
- macOS Apple Silicon：`Keysmith.Switch_0.3.4_aarch64.dmg`
- Windows x64：`Keysmith.Switch_0.3.4_x64-setup.exe`

安装包不使用 Apple Developer ID、公证或 Windows Authenticode。更新包使用独立的生产 minisign 密钥签名；这不是平台代码签名。
